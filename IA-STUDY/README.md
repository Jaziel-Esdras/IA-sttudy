# IA de Estudos

Este projeto é uma base inicial para uma inteligência artificial de apoio ao estudo.

## Objetivo

Organizar:
- tópicos de estudo
- prioridades
- duração estimada por assunto
- plano diário
- resumo de progresso
- sugestões de foco

## Como usar

1. Abra o arquivo `base.py`.
2. Ajuste os tópicos e prioridades.
3. Execute o script com Python.

```bash
python base.py
```

## Próximos passos

- conectar com API de IA
- gerar resumos automáticos
- criar flashcards
- registrar histórico de estudos
- integrar planilhas ou banco de dados

## Estrutura

- `base.py`: núcleo da lógica inicial
- `study_data.json`: arquivo salvo pelo planner (quando usado)
